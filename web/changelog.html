Release Notes & Development History

Comprehensive changelog tracking feature additions, ARM64 freeze resolutions, SRE trampoline expansions, and pipeline improvements.

v8.0 Beta 2

Latest Release

RakNet UDP networking framework integration, 9-library modular shared object (.so) build system, Swordfare Editor (IntelliJ) overhaul with stateful multiline tokenization (LexState), quote-aware .styx theme parsing, Swordigo SDK autocomplete & symbol metadata, 10 OptiX architectural research specifications, and ARM64 JIT stability enhancements.

  • Integrated RakNet cross-platform UDP networking framework with low-level packet serialization and GUID session handshakes.
  • Re-architected build mode into 9 modular shared objects under bin/libs/ with swordfare primary executable.
  • Overhauled Swordfare Editor with stateful multiline tokenization (LexState) and line-level token caching.
  • Integrated Swordigo SDK Autocomplete & Symbol Metadata for Game, Character, Scene, PhysicsObject, Vector3, and Shardshi.
  • Completed 10 OptiX master technical research specifications in docs/optiX/ for high-performance graphics and PBR lighting.
  • Stabilized Dynarmic ARM64 JIT runtime and fixed quote-aware configuration comment stripping.

v8.0 Beta 1

Previous Release

Dynarmic A64 JIT integration, 512MB code cache allocation, unified documentation architecture, AMD FSR 1.0 post-processing upscaling, and complete SwKiwi modloader API compatibility.

  • Engineered 512MB JIT code cache buffer to eliminate compilation basic-block eviction stalls.
  • Enabled Unsafe_UnfuseFMA to route ARM NEON FMA operations directly to x86_64 FMA hardware.
  • Unified documentation and technical research into a single standardized 8-subfolder docs/ hierarchy.
  • Added interactive Raijin Lua debug console and standalone ruby asset previewer tool.

v7.3

Release

GLES 1.1 immediate matrix conversion to modern GPU Vertex Buffer Objects (VBO) and deterministic 60Hz physics accumulator integration.

  • Hooked Mesh::Render to cache immediate vertex pointer arrays into GPU VBO memory.
  • Implemented deterministic 60Hz physics tick stepping, decoupling game logic from 144Hz+ display refresh rates.
  • Expanded SRE trampoline hooks to 34 native function overrides.

v6.0

Release

Wastelands spinlock fix, death freeze elimination, complete GUI DrawRect hook stack, and PostFX preset system.

  • Resolved Wastelands infinite ARM spinlock by overriding GNU copy-on-write std::string atomic operations.
  • Bypassed ad/prompt death freeze via instant checkpoint respawn SRE hook.
  • Implemented multi-preset PostFX pipeline (Cinematic, SSAO, God Rays, CRT Scanlines).
